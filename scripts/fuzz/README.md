# 10000回テスト（あらゆる方向から）

```bash
npm run fuzz            # シードは既定 20261124
node scripts/fuzz/run.mjs 424242          # 別のシード（同じシードなら同じ操作をくり返す）
node scripts/fuzz/run.mjs 1 api           # api / pure / browser だけ
```

| | 件数 | 中身 |
|---|---|---|
| ① ランダムな操作 | 4,000 | 複数のアカウントで、作る・直す・消す・記録・回答・連携・ログアウト・他人の資産に触る、をでたらめな順に。毎回、金額の式・合計・他人のデータが見えないこと・入居者の情報がないこと・タイムラインの順番などを確かめる |
| ② 不正な入力 | 2,000 | 壊れたJSON、巨大な数字・本文、悪意のある文字、壊れたURL、プロトタイプ汚染、パスをさかのぼる読み取り |
| ③ イベント | 500 | 管理会社からのイベントをでたらめに。署名の偽造・他社のオーナー |
| ④ 資料の読み込み | 2,000 | でたらめなCSV・バイト列。入居者の列を読まないこと、金額・年月の形 |
| ⑤ 計算 | 1,000 | 資産価値・ローン・10年の見通し・修繕・部屋の時期 |
| ⑥ 画面 | 400 | 公開ページをでたらめに操作。エラー・横はみ出し・悪意のある文字の実行がないこと |
| ⑦ サーバーと公開ページ | 約180 | 同じ操作で同じ答えが返ること |

結果は `scripts/fuzz/last-report.json`（失敗は場所とシード・手順つき）。
