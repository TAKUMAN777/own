# REVO ASSET

不動産オーナーが **自分で使う** スマホ向けのアプリです。
物件の管理を任せている管理会社（各社が管理システム「REVO管理」を使っている想定）と招待コードでつながり、
複数の管理会社からのご提案・送金・報告書・工事の様子を、1つのアプリでまとめて見られます。
データの正（マスター）は各管理会社の管理システムで、このアプリは「見る」と「回答する」窓口です。

> いまはデモ版です。データはすべて架空で、REVO管理 とは未接続（モックAPI）です。データはサーバーのメモリにあり、再起動で初期状態に戻ります。
> アプリ名は `server/seed.mjs` の `app.name` で変えられます。

## できること（最初の範囲）
1. **ご提案への回答**：A案・B案を比べて、承認／条件付きで承認／差戻し（回答はその管理会社に届く）
2. **収支と送金明細**：月締め済みの月の、全社の合計と、会社ごと・物件ごとの収支とご送金額の内訳
3. **月次報告書**：会社ごとの入居状況（部屋番号まで）・経過のご報告・印刷／PDF保存
4. **工事の進み具合と写真**：発注〜支払済の段階、完了報告の写真
5. **資産（建物）の管理**：建物・部屋・入居・取得価格・借入・固定資産税・保険、表面／実質利回り、月ごとの収支。作り方は3つ
   - 🔗 **管理システムと連携**：REVO管理・REVO MANAGER を使う管理会社の招待コードで、建物・部屋・収支が自動で届く（取得価格などはオーナーが追加）
   - 📄 **管理会社の資料から**：部屋一覧（レントロール）・収支（送金明細）の CSV を読み込む（UTF-8／Shift_JIS、入居者名などの列は読まない）
   - ✍️ **自主管理で入力**：建物・部屋・毎月の収入と支出を自分で入力
   - 見方：**建物ごと／管理会社ごと／管理方法（管理会社に委託・自主管理）**で、資産価値・入居・賃料の小計
   - **資産価値**：査定額、なければ「年間の手取り（賃料−運営費）÷ 想定の利回り（構造ごと、変更可）」の目安。純資産（価値−借入）と取得価格との差
   - **過去・いま・未来**：建物ごとに切り替え。過去＝月ごとの収支と出来事、いま＝価値・入居・利回り、未来＝10年の手取りの見通しと予定
   - **タイムライン**：全体・建物・部屋の3つの単位。竣工・取得・管理委託・収支・ご提案・工事・入居／退去・契約更新・修繕の目安・ローン完済・法定耐用年数
   - **部屋**：部屋ごとの賃料・入居・次の契約更新と、その部屋の出来事（入居者の情報は持たない）
6. **管理会社とのつながり**：招待コードで会社を追加、お問い合わせ先

デモの招待コード：`HKT-0001`（田中様・〇〇不動産管理）、`HKT-0002`（山本様）。
田中様はメニュー →「管理会社」で `TNJ-0011`（REVO管理の2社目）、`MGR-0021`（REVO MANAGER の会社）を入れると、つながる会社が増えます。
資料からの作成は、画面の「見本」CSV で試せます。

## 動かし方
```bash
npm start          # http://localhost:8791/ （PORT で変更可）
npm test           # API とルールの自動確認
```
Node.js 20 以上。依存パッケージはありません。

## サーバーなしの公開デモ
```bash
node scripts/build-static.mjs   # dist/revo-asset.html（1枚で動く。データはページの中だけ、再読み込みで初期状態）
```

## 構成
- `public/` 画面（ビルド不要の静的JS、ハッシュルーティング）
- `server/server.mjs` 静的配信と API（`/api/v1`）
- `server/store.mjs` オーナーのアカウント・管理会社とのつながり・ルール（本番では各社の REVO管理 API の呼び出しに置き換える）
- `server/seed.mjs` 架空のデモデータ（3社・自主管理の貸家1件）
- `public/csv.js` 管理会社の資料（CSV）の読み込み
- `docs/API.md` API（アプリ用）と、管理会社（REVO管理）との連動の約束
- `scripts/api.test.mjs` 自動確認

## 守っていること
- 管理会社の金額は各社の計算結果をそのまま表示（会社をまたぐ合計だけサーバーで足す）。利回りなどの指標と、自主管理・資料の収支はこのアプリで計算
- 取得価格・借入などオーナー自身の情報は、管理会社には送らない
- 月締め前の月の数字は出さない
- 入居者の個人情報は扱わない（部屋番号まで。資料の氏名・電話の列は読まず、サーバーも受け取らない）
- オーナーの回答は「記録」。発注・送金などの確定は管理会社の担当者が行う
- つながっていない会社・他のオーナーのデータや写真は見られない
