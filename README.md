# オーナー向けサービス（ホワイトラベル）

不動産管理会社が **自社ブランド** でオーナーに提供する、スマホ向けのWebサービスです。
データの正（マスター）は管理会社の管理システム（REVO管理）で、このサービスは「見る」と「回答する」窓口です。
オーナーに見える画面には、管理会社のサービス名・会社名だけを出します（例：`博多オーナーズ｜〇〇不動産管理株式会社`）。

> いまはデモ版です。データはすべて架空で、REVO管理 とは未接続（モックAPI）です。

## できること（最初の範囲）
1. **ご提案への回答**：A案・B案を比べて、承認／条件付きで承認／差戻し
2. **収支と送金明細**：月締め済みの月の、物件ごとの収支とご送金額の内訳（工事代金の差引を含む）
3. **月次報告書**：入居状況（部屋番号まで）・経過のご報告・印刷／PDF保存
4. **工事の進み具合と写真**：発注〜支払済の段階、完了報告の写真

ログインは管理会社が発行する **招待コード**（デモ：`HKT-0001` 田中様、`HKT-0002` 山本様）。

## 動かし方
```bash
npm start          # http://localhost:8791/ （PORT で変更可）
npm test           # API とルールの自動確認
```
Node.js 20 以上。依存パッケージはありません。

## 構成
- `public/` 画面（ビルド不要の静的JS、ハッシュルーティング `#/home` `#/proposals` `#/money` `#/reports` `#/works`）
- `server/server.mjs` 静的配信と API（`/api/v1`）
- `server/store.mjs` データの取り出しとルール（本番では REVO管理 API の呼び出しに置き換える）
- `server/seed.mjs` 架空のデモデータ
- `docs/API.md` REVO管理 との連動API（共通の約束）
- `scripts/api.test.mjs` 自動確認

## 守っていること
- 金額は REVO管理 の計算結果をそのまま表示（画面では再計算しない）
- 月締め前の月の数字は出さない
- 入居者の個人情報は扱わない（部屋番号まで）
- オーナーの回答は「記録」。発注・送金などの確定は管理会社の担当者が行う
- 他のオーナーのデータ・写真は見られない
- 画面に REVO の名前を出さない（テストで確認）
